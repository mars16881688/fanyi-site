네 가지 언어

한국어·중국어·영어·일본어, 어떤 조합이든.

설정에서 「내 언어」만 고르면 됩니다. 외국어는 내 언어로 번역하고, 답장은 상대방의 언어로 돌려보냅니다.

한 번에 답장

상대는 상대의 언어로, 나는 한국어로.

외국어 메시지는 한국어로 번역됩니다. 한국어로 답장을 쓰고 ⌘↩를 누르면 상대방의 언어로 나옵니다. 영어에는 영어로, 일본어에는 일본어로.

EN

상대Can you send the deck before Thursday?

한

번역문목요일 전에 발표 자료를 보내 줄 수 있나요?

한

입력네, 수요일 저녁까지 보낼게요.

EN

보냄Sure, I'll send it over by Wednesday evening.

문맥 이해

같은 말도 상황에 맞게.

원래 있던 기능처럼.

메뉴 막대에 있고 Dock에는 나타나지 않습니다. 카드는 시스템의 반투명 재질을 쓰며 라이트·다크 모드와 시스템 언어를 따릅니다. Esc를 누르거나 바깥을 클릭하면 닫힙니다.

개인정보

텍스트는 내가 정한 곳으로만.

Suiyi는 자체 서버가 없습니다. 요청은 직접 설정한 모델 API로만 전송됩니다.

  • 원격 분석 없음

    어떤 통계도 수집하지 않습니다. 기본적으로 선택한 텍스트를 디스크에 저장하지 않습니다.

  • 키는 키체인에

    API 키는 macOS 키체인에 저장됩니다. 엔드포인트와 모델은 직접 정합니다.

  • 완전 로컬도 가능

    로컬 Ollama에 연결하면 요청이 Mac 밖으로 나가지 않습니다.

  • 민감한 곳에서는 동작하지 않음

    비밀번호 앱, 비밀번호 칸, 보안 입력 중에는 표시되지 않습니다. 비밀번호나 키, 카드 번호처럼 보이는 선택은 한 번 더 확인한 뒤에 보냅니다. 앱별로 제외할 수도 있습니다.

정확히 말하면: 번역할 때 선택한 텍스트, 앱 이름, 윈도우 제목, 주변 문장이 설정한 API로 전송됩니다. 선택한 텍스트를 가져올 수 없는 앱에서는 클립보드를 한 번 읽고 바로 되돌립니다. 「나답게」를 켜면 스타일 프로필도 답장 요청과 함께 전송됩니다. Suiyi는 하루에 한 번 이 사이트의 버전 정보를 읽어 업데이트를 확인합니다(설정에서 끌 수 있음). 개인 데이터는 보내지 않습니다.

FAQ

사용하기 전에 알아 두면 좋은 것.

어떤 언어를 지원하나요?

한국어·중국어·영어·일본어를 어떤 조합으로든 번역합니다. 설정에서 「내 언어」를 고르면 외국어는 내 언어로, 내 언어는 「자주 쓰는 상대 언어」로 번역하고, 답장은 상대방의 언어로 돌려보냅니다. 프랑스어 등 다른 언어도 내 언어로 번역할 수 있습니다.

앱은 어떤 언어로 표시되나요?

macOS 언어에 맞춰 간체 중국어, English, 日本語, 한국어로 표시됩니다. 그 밖의 시스템 언어에서는 영어로 표시됩니다.

API 키가 따로 필요한가요?

네. OpenAI 호환 API라면 무엇이든 쓸 수 있습니다. 기본값은 DeepSeek이며 OpenAI, OpenRouter, 로컬 Ollama도 가능합니다. 요금은 각 제공업체의 사용량 기준입니다.

왜 손쉬운 사용 권한이 필요한가요?

선택한 텍스트를 읽고 다시 쓴 결과로 바꾸려면 이 macOS 권한이 필요합니다. 권한이 없으면 Suiyi가 동작하지 않습니다.

텍스트가 저장되나요?

기본적으로 저장하지 않습니다. 「나답게」를 켠 경우에만 기록과 스타일 프로필을 Mac의 ~/.suiyi에 저장하며 언제든 삭제할 수 있습니다.

어떤 앱에서 쓸 수 있나요?

텍스트를 선택할 수 있는 대부분의 앱에서 쓸 수 있습니다. 브라우저, Slack, Teams, 메일 등. 터미널과 코드 편집기는 키가 자주 표시되므로 기본값이 꺼짐이며, 필요하면 설정 › 보안에서 켤 수 있습니다. 쓰고 싶지 않은 앱은 설정에서 제외할 수 있습니다.

어떻게 업데이트하나요?

새 버전이 나오면 Suiyi가 알려 줍니다. 「지금 업데이트」를 누르면 다운로드하고 서명을 확인한 뒤 교체하고 다시 엽니다. 설정과 권한은 그대로 유지됩니다. 메뉴의 「업데이트 확인…」으로도 확인할 수 있습니다. 0.2.4 이하 버전은 0.2.5를 한 번만 직접 다운로드하세요.

설치 방법

zip을 받았다면 다음 5단계로 시작할 수 있습니다.

  1. 1

    응용 프로그램으로 이동

    압축을 풀고 Suiyi.app을 「응용 프로그램」 폴더로 드래그한 뒤 엽니다.

  2. 2

    열기 허용

    "개발자를 확인할 수 없습니다"라는 메시지가 나오면 시스템 설정 › 개인정보 보호 및 보안을 열고 맨 아래에서 「그래도 열기」를 클릭한 뒤 확인합니다. 처음 한 번만 하면 됩니다.

  3. 3

    손쉬운 사용 권한 허용

    안내에 따라 시스템 설정 › 개인정보 보호 및 보안 › 손쉬운 사용에서 Suiyi를 켜고, Suiyi를 종료했다가 다시 엽니다.

  4. 4

    API 키 입력

    메뉴 막대의 Suiyi 아이콘 › 설정…에서 API 키를 입력하고(OpenAI 호환 API, 기본값 DeepSeek) 「연결 테스트」 후 「저장」을 클릭합니다.

  5. 5

    내 언어 선택

    설정에서 「내 언어」를 선택합니다. 이후 어떤 앱에서든 텍스트를 선택하고 옆의 작은 버튼을 누르면 번역됩니다. ⌥⌘T는 번역, ⌥⌘R은 다시 쓰기입니다.

2단계에서 「그래도 열기」가 보이지 않으면 터미널에서 다음을 실행하세요:
xattr -dr com.apple.quarantine /Applications/Suiyi.app

One more thing

Longbridge 동료들을 위한 안내

회사 모델 서비스를 Suiyi에서 바로 쓸 수 있습니다. 다음 3단계로 설정하세요.

  1. 1

    API 키 발급

    lboneapi.longbridge-inc.com에 접속해 로그인한 뒤 내 API 키를 발급받습니다.

  2. 2

    모델 서비스 입력

    메뉴 막대의 Suiyi 아이콘 › 설정…을 열고 「모델 서비스」에 다음을 입력합니다:

    • API Key발급받은 키
    • Base URLhttps://lboneapi.longbridge-inc.com/v1
    • 모델gpt-4o
  3. 3

    테스트 후 저장

    「연결 테스트」로 연결을 확인한 뒤 오른쪽 아래의 「저장」을 클릭합니다.

API 키는 다른 사람과 공유하지 말고 각자 자신의 키를 사용하세요.
