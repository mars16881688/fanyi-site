为什么

回一条英文消息，
以前七步，现在三步。

以前

  1. 复制原文
  2. 切到翻译网页，粘贴
  3. 读译文，想怎么回
  4. 写好中文
  5. 再贴进去译成英文
  6. 改掉生硬的语气
  7. 复制回去，发送

用随译

  1. 选中原文，读译文
  2. 写中文回复，按 ⌘↩
  3. 复制，发送

全程不离开当前窗口。

功能

看懂、回复、写得像你。

一键回复

英文消息先译成中文。你用中文写回复，按 ⌘↩，转成英文，复制即发。

中

EN

发出Sure, I'll send it over by end of day Wednesday.

改写

一句话，三种口吻。

选中后点「改写」或按 ⌥⌘R，同语言给出三个版本。原文可编辑时，一键替换。

我想问一下这个事情现在进展怎么样了。

  • 简洁这件事进展如何？
  • 正式请问该事项目前进展如何？
  • 口语那件事现在咋样了？

像你写的 默认关闭

英文回复，也是你的口吻。

主动开启后，随译从你的历史里整理出一份风格档案，英文回复贴近你平时的语气和长度。文件只存在本机。

~/.suiyi/history.jsonl ~/.suiyi/profile.md

Codex 和 Claude Code 也能读取这份档案，代你写作时同样像你。

原生 macOS

像系统自带的一样。

只住在菜单栏，没有 Dock 图标。弹窗用系统毛玻璃，跟随浅色、深色；不用时按 Esc 或点外面就收起。

  • ⌥⌘T 翻译
  • ⌥⌘R 改写
  • ⌘↩ 生成英文回复

隐私

你的文字，只去你选的地方。

随译没有自己的服务器。请求只发往你配置的模型接口。

  • 无遥测

    不收集任何统计数据。默认不把选中文字写入磁盘。

  • Key 在钥匙串

    API Key 存在 macOS 钥匙串，接口和模型由你决定。

  • 可以全在本机

    接本地 Ollama，请求不出你的 Mac。

  • 敏感处不触发

    密码框、安全输入状态下不弹出；也可按 App 排除。

说清楚：翻译时，选中文字、当前 App 名、窗口标题和附近文字会发送到你配置的接口。少数 App 不提供选中文字时，随译会临时读一次剪贴板，随即恢复原内容。开启「像你写的」后，风格档案会随回复请求一起发送。

问答

用之前，你可能想知道。

需要自己的 API Key 吗？

需要。任何 OpenAI 兼容接口都行，默认 DeepSeek，也可以用 OpenAI、OpenRouter 或本地 Ollama。调用费用由你的服务商按量收取。

为什么要辅助功能权限？

读取你选中的文字、把改写结果替换回原位置，都需要这个 macOS 系统权限。没有它，随译无法工作。

支持哪些语言？

默认自动：中文译成英文，其他语言译成简体中文。也可以固定译成简体中文、English 或日本語。

我的文字会被保存吗？

默认不会。只有主动开启「像你写的」，历史和风格档案才会保存在本机 ~/.suiyi，随时可以删除。

哪些 App 里能用？

大多数能选中文字的 App 都能用，包括浏览器、Slack、邮件和终端。不想触发的 App 可以在设置里排除。
