示意演示 · 选中英文消息

小工具，刚刚好

一个小按钮，
三种能力。

翻译、改写、回复。顺着你的工作方式来。

01 · 划词

划词即译

点击或悬停展开小圆按钮，译文流式出现。结合应用、窗口标题与附近文字，理解语境和语气。

Make yourself understood.译
⌥⌘T 翻译⌥⌘R 改写

自动：中文 → 英文，其他语言 → 简体中文
也可固定目标：简体中文 / English / 日本語

02 · 改写

同一个意思，
换一种说法。

一次给出三个版本，每个版本都能复制，或在可编辑处替换。

更简洁 周四见。更正式 期待周四与您交流。更口语 那就周四聊！

03 · 回复

用中文想，
用英文说。

看完译文，直接输入中文回复。按 ⌘↩，英文回复流式生成，单独复制。

EN原文→中译文→中回复→EN回复

04 · 接口

模型，由你选择。

任何 OpenAI 兼容 API。填入自己的配置，用「测试连接」确认。

DeepSeek 默认OpenAIOpenRouterOllama 本地
⌘自带 Key，存于钥匙串

05 · 我的风格 默认关闭

让回复，像你。

主动开启「回复时参考我的风格」，让英文回复贴近你的语气与长度。

~/.fanyi/profile.md
CodexClaude Code

用自己的 API 生成画像，保留你写的「## 我的补充」。点击接入后，只在自己的 AGENTS.md / CLAUDE.md 添加可移除的标记块。

06 · 随你习惯

安静待在菜单栏。

没有 Dock 图标。浅色、深色模式随你选；用 bundle ID 排除不需要触发的应用。

浅色
深色

密码输入框与安全输入时不触发。

02 / 阅读

读英文文档与代码注释

原文

Returns the cached result if available.

译文

03 / 写作

写英文邮件与 PR 描述

先把意思写清楚，再译成自然的英文。

中文

英文

Fix the state not updating after saving settings.

04 / 润色

润色中文表达

用「改写」调整语气，让表达更合适。

原文

我想问一下这个事情现在进展怎么样了。

更简洁

这件事进展如何？

不打断你的节奏

三步，接着做你的事。

  1. 01

    选中文字

    在正在使用的应用里，
    选中你想理解或调整的文字。

  2. 02

    点小圆按钮

    点击或悬停，展开翻译 / 改写。
    也可以直接按快捷键。

  3. 03

    复制 / 替换 / 回复

    卡片可拖动；原位置可编辑时可替换。
    按 Esc 或点击外部，收起卡片。

你的文字，你的选择

只发送你选中的文字。其余，一概不碰。

触发翻译时附带少量周边上下文，帮助理解语境。
请求发往你配置的 API，没有遥测。

↗

只有触发，才发送

翻译、改写和回复按你的操作发起，选中文字与少量上下文只发送到你自己的接口。

∅

无遥测

不收集键盘、屏幕或剪贴板历史。密码输入框与安全输入时不触发。

⌘

Key 存于钥匙串

自带 API Key，保存在 macOS Keychain。接口与模型配置由你掌握。

⌂

历史与画像，默认关闭

主动开启后，文件只保存在本机 ~/.fanyi/。历史文件为 history.jsonl，画像为 profile.md。

✓ 选中文字 → 你的接口× 不收集键盘 / 屏幕 / 剪贴板历史

主动开启历史后，画像会使用你配置的 API 生成，相关历史会随请求发送；启用「我的风格」时，风格背景会随英文回复请求发送。使用本地 Ollama，可让这些请求也留在本机。

从源码，开始使用

让文字，流动起来。

为你的 Mac 装上这个小按钮。

TERMINAL
git clone https://github.com/mars16881688/fanyi && cd fanyi && ./build.sh && ./install.sh

macOS 13+ · 需要 Command Line Tools · 安装后授予辅助功能权限

未安装 Command Line Tools？先运行 xcode-select --install。
可选：构建前运行 scripts/create-signing-cert.sh，使用稳定签名。
启动后填写自己的 API Key，并用「测试连接」确认配置。
