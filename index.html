三种语言

中英日，两两互译。

每个人在设置里选「我的语言」。外语一律译成你的语言；回复时，再译回对方的语言。

为什么

回一条外语消息，
以前七步，现在三步。

以前

  1. 复制原文
  2. 切到翻译网页，粘贴
  3. 读译文，想怎么回
  4. 写好中文
  5. 再贴进去译成对方的语言
  6. 改掉生硬的语气
  7. 复制回去，发送

用随译

  1. 选中原文，读译文
  2. 用中文写回复，按 ⌘↩
  3. 复制，发送

全程不离开当前窗口。

功能

看懂、回复、写得像你。

一键回复

对方写外语，你写中文。

外语消息先译成中文。你用中文写回复，按 ⌘↩，译回对方的语言：英文消息回英文，日文消息回日文。

JA

对方明日の打ち合わせ、15時からに変更できますか？

中

译文明天的会可以改到下午三点吗？

中

我写可以，三点见。

JA

发出大丈夫です。15時にお会いしましょう。

懂上下文

同一个词，按场景译。

翻译时参考当前 App、窗口标题和选中文字前后的内容。终端里的报错、聊天里的口语、邮件里的客套，各按各的译。

ship it Friday

无上下文周五把它运走
Slack · #release周五上线

改写

一句话，三种口吻。

在卡片顶部切到「改写」或按 ⌥⌘R，同语言给出三个版本，中英日都行。原文可编辑时，一键替换。

我想问一下这个事情现在进展怎么样了。

  • 简洁这件事进展如何？
  • 正式请问该事项目前进展如何？
  • 口语那件事现在咋样了？

像你写的 默认关闭

发出去的回复，也是你的口吻。

主动开启后，随译从你的历史里整理出一份风格档案，回复贴近你平时的语气和长度。文件只存在本机。

~/.suiyi/history.jsonl ~/.suiyi/profile.md

Codex 和 Claude Code 也能读取这份档案，代你写作时同样像你。

CodexClaude Code

原生 macOS

像系统自带的一样。

只住在菜单栏，没有 Dock 图标。弹窗用系统毛玻璃，跟随浅色、深色；界面跟随系统语言。不用时按 Esc 或点外面就收起。

  • ⌥⌘T 翻译
  • ⌥⌘R 改写
  • ⌘↩ 生成回复

隐私

你的文字，只去你选的地方。

随译没有自己的服务器。请求只发往你配置的模型接口。

  • 无遥测

    不收集任何统计数据。默认不把选中文字写入磁盘。

  • Key 在钥匙串

    API Key 存在 macOS 钥匙串，接口和模型由你决定。

  • 可以全在本机

    接本地 Ollama，请求不出你的 Mac。

  • 敏感处不触发

    密码框、安全输入状态下不弹出；也可按 App 排除。

说清楚：翻译时，选中文字、当前 App 名、窗口标题和附近文字会发送到你配置的接口。少数 App 不提供选中文字时，随译会临时读一次剪贴板，随即恢复原内容。开启「像你写的」后，风格档案会随回复请求一起发送。菜单里的「检查更新」只在你点击时读取本站的版本文件。

问答

用之前，你可能想知道。

支持哪些语言？

中文、英文、日文任意两两互译。在设置里选「我的语言」：外语译成你的语言，你的语言译成「常用对外语言」，回复译回对方的语言。韩文、法文等其他语言也能译成你的语言。

界面是什么语言？

跟随 macOS 系统语言，支持简体中文、English、日本語；其他系统语言显示英文。

需要自己的 API Key 吗？

需要。任何 OpenAI 兼容接口都行，默认 DeepSeek，也可以用 OpenAI、OpenRouter 或本地 Ollama。调用费用由你的服务商按量收取。

为什么要辅助功能权限？

读取你选中的文字、把改写结果替换回原位置，都需要这个 macOS 系统权限。没有它，随译无法工作。

我的文字会被保存吗？

默认不会。只有主动开启「像你写的」，历史和风格档案才会保存在本机 ~/.suiyi，随时可以删除。

哪些 App 里能用？

大多数能选中文字的 App 都能用，包括浏览器、Slack、钉钉、邮件和终端。不想触发的 App 可以在设置里排除。

安装步骤

下载压缩包后，照着做一遍就能用。

  1. 1

    拖进「应用程序」

    解压后把 Suiyi.app 拖进「应用程序」文件夹，双击打开。

  2. 2

    允许打开

    系统提示「无法验证开发者」时，打开 系统设置 › 隐私与安全性，滚动到底部点「仍要打开」，再确认一次。只需做一次。

  3. 3

    授予辅助功能权限

    按提示打开 系统设置 › 隐私与安全性 › 辅助功能 里的「随译」，然后退出随译再打开一次。

  4. 4

    填写 API Key

    点菜单栏的随译图标 › 设置…，填写 API Key（任意 OpenAI 兼容接口，默认 DeepSeek），点「测试连接」，再点「保存」。

  5. 5

    选择我的语言

    在设置里选「我的语言」。之后在任何 App 里选中文字，点旁边的小按钮即可翻译；⌥⌘T 翻译，⌥⌘R 改写。

第 2 步找不到「仍要打开」？在「终端」运行：
xattr -dr com.apple.quarantine /Applications/Suiyi.app
