macOS 菜单栏划词翻译

选中就懂。中文写，英文发。

在任何 App 里选中文字，旁边出现一个小按钮，点一下就翻译或改写。收到英文消息，用中文写回复，Fanyi 译成地道英文。

怎么用

不切窗口，四步说清楚。

  1. 01

    选中

    拖选或双击文字，鼠标旁出现小圆按钮。不用就自动消失。

  2. 02

    翻译

    中文译成英文，其他语言译成中文。也可直接按 ⌥⌘T。

  3. 03

    回复

    看懂之后，用中文写回复，⌘↩ 生成英文。

  4. 04

    按你的风格写

    可选，默认关闭。英文回复贴近你平时的语气和长度。

功能

翻译、改写、回复，一张卡片。

一键回复

对方写英文，你写中文。

英文消息先译成中文；你用中文写回复，Fanyi 译回英文，复制即发。

EN

对方Can you send the deck before Thursday?

中

译文你能在周四前把演示文稿发过来吗？

中

我写可以，周三下班前发你。

EN

发出Sure, I'll send it over by end of day Wednesday.

理解上下文

同一个词，按场景译。

翻译时参考当前 App、窗口标题和选中文字前后的内容。终端里的报错、聊天里的口语、邮件里的客套，各按各的译。

改写

一句话，三种口吻。

选中后点「改写」或按 ⌥⌘R，同语言给出三个版本。原文可编辑时，一键替换。

我想问一下这个事情现在进展怎么样了。

  • 简洁这件事进展如何？
  • 正式请问该事项目前进展如何？
  • 口语那件事现在咋样了？

毛玻璃弹窗

像系统自带的一样。

用系统原生的毛玻璃材质，自动跟随浅色、深色。卡片可拖动，按 Esc 或点外面就收起。

个人风格 默认关闭

回复像你写的。

主动开启后，历史和风格档案只存在本机 ~/.fanyi。回复时参考你的语气；Codex 和 Claude Code 也能读取，代你写作时更像你。

隐私

你的文字，不经过我们。

Fanyi 没有服务器。请求只发往你自己配置的接口。

  • 无遥测

    不收集任何统计数据。默认不把选中文字写入磁盘。

  • Key 在钥匙串

    API Key 存在 macOS 钥匙串，接口和模型由你决定。

  • 用你的接口

    任意 OpenAI 兼容接口，默认 DeepSeek。也可接本地 Ollama。

  • 敏感处不触发

    密码框、安全输入状态下不弹出；也可按 App 排除。

说清楚：翻译时，选中文字、当前 App 名、窗口标题和附近文字会发送到你配置的接口。部分 App 不提供选中文字时，Fanyi 会临时读取一次剪贴板，随即恢复原内容。开启个人风格后，风格档案会随回复请求一起发送。
