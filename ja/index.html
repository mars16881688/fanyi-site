機能

理解して、返信して、自分らしく。

ワンステップ返信

相手は相手の言語で、あなたは日本語で。

外国語のメッセージは日本語に翻訳。日本語で返信を書いて ⌘↩ を押せば、相手の言語で出てきます。中国語には中国語、英語には英語で。

EN

相手Can you send the deck before Thursday?

日

訳文木曜日までに資料を送ってもらえますか？

日

入力はい、水曜の夕方までに送ります。

EN

送信Sure, I'll send it over by Wednesday evening.

文脈を理解

同じ言葉も、場面に合わせて。

使っているアプリ、ウインドウのタイトル、選択部分の前後の文章を参考に翻訳します。チャットのくだけた言い方、メールの丁寧な表現、文書の専門用語、それぞれに合った訳に。

文脈なし金曜日に発送する
Slack · #release金曜日にリリースする

書き換え

ひとつの文を、3 つのトーンで。

カードを「書き換え」タブに切り替えるか、⌥⌘R。同じ言語のまま 3 パターンを提案します。日中英韓どれでも OK。編集できる場所ならワンクリックで置き換え。

この件、いまどうなっているか確認させていただきたいのですが。

  • 簡潔この件、進捗はいかがですか？
  • 丁寧本件の進捗状況をお知らせいただけますでしょうか。
  • カジュアルあの件、どうなった？

あなたらしく 既定ではオフ

どの言語の返信も、あなたの口調で。

オンにすると、履歴からスタイルプロファイルを作り、返信をふだんの口調や長さに近づけます。ファイルは Mac の中だけに保存されます。

~/.suiyi/history.jsonl ~/.suiyi/profile.md

ネイティブ macOS

まるで標準機能のように。

メニューバーに常駐し、Dock には表示されません。カードはシステムのすりガラス素材で、ライト／ダークに追従。表示言語もシステムに合わせます。Esc か外側のクリックで閉じます。

  • ⌥⌘T 翻訳
  • ⌥⌘R 書き換え
  • ⌘↩ 返信を翻訳

プライバシー

テキストは、あなたが選んだ送り先にだけ。

Suiyi は独自のサーバーを持ちません。リクエストは自分で設定したモデル API にだけ送られます。

  • テレメトリなし

    統計データは一切収集しません。既定では選択テキストをディスクに保存しません。

  • キーはキーチェーンに

    API キーは macOS のキーチェーンに保存。接続先とモデルはあなたが決めます。

  • 完全ローカルも可能

    ローカルの Ollama につなげば、リクエストは Mac の外に出ません。

  • 機密入力では動作しない

    パスワード管理アプリ、パスワード欄、セキュア入力中は表示されません。パスワードやキー、カード番号のような選択は、もう一度確認してから送信します。アプリ単位で除外もできます。

正確に言うと：翻訳時には、選択テキスト、アプリ名、ウインドウのタイトル、周辺の文章が設定した API に送信されます。選択テキストを取得できないアプリでは、一度だけクリップボードを読み取り、すぐ元に戻します。「あなたらしく」をオンにすると、スタイルプロファイルも返信のリクエストと一緒に送信されます。1 日に 1 回、このサイトのバージョン情報を読み込んでアップデートを確認します（設定でオフにできます）。個人データは送信しません。

FAQ

使う前に知っておきたいこと。

どの言語に対応していますか？

日本語・中国語・英語・韓国語をどの組み合わせでも翻訳できます。設定で「自分の言語」を選ぶと、外国語は自分の言語に、自分の言語は「よく使う相手の言語」に翻訳し、返信は相手の言語に戻します。フランス語やドイツ語なども自分の言語に翻訳できます。

アプリの表示言語は？

macOS の言語に合わせて、簡体中国語・English・日本語・한국어で表示します。それ以外のシステム言語では英語になります。

自分の API キーが必要ですか？

はい。OpenAI 互換の API ならどれでも使えます。既定は DeepSeek で、OpenAI、OpenRouter、ローカルの Ollama も利用できます。料金は各プロバイダの従量課金です。

なぜアクセシビリティの許可が必要ですか？

選択したテキストの読み取りや、書き換え結果での置き換えに、この macOS の権限が必要です。許可がないと Suiyi は動作しません。

テキストは保存されますか？

既定では保存しません。「あなたらしく」をオンにした場合のみ、履歴とスタイルプロファイルを Mac の ~/.suiyi に保存し、いつでも削除できます。

どのアプリで使えますか？

テキストを選択できるほとんどのアプリで使えます。ブラウザ、Slack、Teams、メールなど。ターミナルとコードエディタはキーが表示されることが多いため既定でオフで、必要なら 設定 › セキュリティ でオンにできます。使いたくないアプリは設定で除外できます。

アップデートの方法は？

新しいバージョンが出ると Suiyi が知らせます。「今すぐアップデート」をクリックすると、ダウンロードして署名を確認し、置き換えて再起動します。設定や権限はそのまま残ります。メニューの「アップデートを確認…」からも確認できます。0.2.4 以前のバージョンは、0.2.5 を一度だけ手動でダウンロードしてください。

インストール手順

zip を受け取ったら、この 5 ステップで使い始められます。

  1. 1

    アプリケーションへ移動

    解凍した Suiyi.app を「アプリケーション」フォルダにドラッグして開きます。

  2. 2

    開くことを許可

    「開発元を検証できません」と表示されたら、システム設定 › プライバシーとセキュリティ を開き、一番下の「このまま開く」をクリックして確認します。最初の一回だけです。

  3. 3

    アクセシビリティを許可

    案内に従って システム設定 › プライバシーとセキュリティ › アクセシビリティ で Suiyi をオンにし、Suiyi をいったん終了してもう一度開きます。

  4. 4

    API キーを入力

    メニューバーの Suiyi アイコン › 設定… で API キーを入力し（OpenAI 互換の API。既定は DeepSeek）、「接続テスト」のあと「保存」をクリックします。

  5. 5

    自分の言語を選ぶ

    設定で「自分の言語」を選びます。あとはどのアプリでもテキストを選択し、横の小さなボタンで翻訳できます。⌥⌘T で翻訳、⌥⌘R で書き換え。

手順 2 で「このまま開く」が見つからない場合は、ターミナルで次を実行してください：
xattr -dr com.apple.quarantine /Applications/Suiyi.app

One more thing

Longbridge の皆さんへのガイド

社内のモデルサービスをそのまま Suiyi で使えます。次の 3 ステップで設定してください。

  1. 1

    API キーを取得

    lboneapi.longbridge-inc.com を開き、ログインして自分の API キーを取得します。

  2. 2

    モデルサービスを入力

    メニューバーの Suiyi アイコン › 設定… を開き、「モデルサービス」に次を入力します：

    • API Key取得したキー
    • Base URLhttps://lboneapi.longbridge-inc.com/v1
    • モデルgpt-4o
  3. 3

    テストして保存

    「接続テスト」で接続を確認したら、右下の「保存」をクリックします。

API キーは他の人と共有せず、各自のものを使ってください。
